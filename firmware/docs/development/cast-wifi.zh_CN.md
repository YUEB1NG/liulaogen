# Wi-Fi 与网站上传

r5 已替代下方早期单份资料缓存和每行 11 字限制：参见 [r5 行为与容量](../../../docs/r5-update.zh_CN.md)。当前使用 15 天不可变缓存和每行 13 字简介。

版本 `cast-wifi-20261007-r4`，本机 Windows ESP-IDF 5.5.3，ESP32-C3、8 MB Flash、
无 PSRAM。保留已认可的八城离线应用、历史资料、深灰蓝色界面、背光修复和原有浏览操作。

## 日常操作

1. 城市首页长按 OK 进入更新，长按上键进入网络设置。
2. 选择“选择 Wi-Fi”，扫描并选择 2.4 GHz 个人网络，在 Passport 输入密码。
   上下选字符，OK 输入；长按上键切换小写、大写、数字、符号/空格，每组都有删除选项。
   长按下键完成，长按 OK 取消并清空输入。密码显示星号；支持全部 95 个可打印 ASCII 字符。
   开放网络留空，个人网络密码为 8–63 位。隐藏网络手动输入支持英文名称；扫描所得 UTF-8
   名称按原字节连接，字库外名称显示提示。密码不会发送到网站。
3. 等待连接并保存成功。密码错误、30 秒 DHCP 超时、NVS 保存失败均恢复旧配置。
   已存网络开机重连，断线每 15 秒重试。无需重命名手机热点、打开 192.168.4.1 或随身带电脑。
4. 在“更新服务地址”输入部署网站的根地址，无路径/末尾斜杠。用户尚未决定域名，因此固件
   未预填地址。公网必须 HTTPS，保持证书校验并等待网络校时；本机测试另允许 RFC1918
   私网 IPv4 HTTP。连接 Wi-Fi 不等于连接网站；服务地址可在 Wi-Fi 配置之前保存。
5. 选择“网站配对”，在手机网站“上传到设备”中输入设备八位配对码。有效期五分钟，OK
   重新申请。网站需管理员登录；每台设备与每个服务初次配对一次。
6. 网站选择日期，编辑、保存、预览并发布名单，再点“上传到设备”，选择在线 Passport，
   点“上传到此设备”。上传所选日期全部已发布城市/场次，并非仅当前编辑的城市。
   草稿不上传，发布本身也不会自动排队上传。使用公网服务时，手机和 Passport 各自能上网即可，
   无需处于同一局域网。
7. 网站依次显示等待设备、传输中、设备已保存。设备每十秒查询明确提交的任务，网站超过
   45 秒未收到心跳显示离线；必须收到匹配的保存回执才算成功。断网可继续看最近保存的名单。

Passport 原有手动更新保留：上下调日期，OK 下载，长按下键在校时后使用中国日期。
长按 OK 返回。“清除网络配置”需要 OK 确认，保留已存名单。旧网页配网/热点预设代码保留
用于回归兼容，但 r4 网络设置不再提供这两种入口。

## 上传校验与范围

设备生成并保存随机标识和密钥，绑定单一服务地址；网站仅保存密钥哈希，管理员密码不会
传到设备。心跳与下载独立鉴权，管理员接口继续验证会话和 CSRF。应用代码不记录凭据；
Wi-Fi 驱动原始日志可能含 SSID，分享前需脱敏。

每台已配对设备最多一个未完成任务，冻结已发布名单。设备校验日期、版本、格式、字库、
大小及版本回退，再双槽写入 NVS、读回核验、切换有效槽，之后才排队持久回执。
重试或重启不会将未完成下载误报成功。失败后可重新上传；移除设备会取消任务，需再次配对。
网站重启保留配对与任务，在线状态待新心跳恢复。上限：32 台配对设备、64 个临时配对申请、
管理员每分钟十次配对尝试、名单 8192 字节、总计 80 组、每场 12 组、姓名 24 字节。
这是内容更新，不是固件 OTA。

在线演员资料仍在打开组合时通过同一工作任务下载，必须匹配日期、版本和成员顺序，
仅缓存最后一个组合。该日期重新发布后，旧上传任务中的未缓存资料可能无法取得；显示历史/
待更新回退内容。上传成功仅代表名单已保存，不代表全部演员资料已预先下载。

## 存储与验证

NVS：0x9000/0x16000；PHY：0x1f000/0x1000；应用：0x20000/0x7e0000。
经校验合并镜像从 0x0 写入，其填充区域会重置配置/缓存；只使用匹配 ELF/MAP，不全片擦除。
6875 字字库与历史数据未改变。HTTP/TLS 缓冲在解析和存储前释放，原同步工作任务串行处理
心跳、名单、资料，不新增音频或蓝牙栈。

运行完整 `tools/validate.ps1 --all`，网站运行 `python -m unittest -v test_api test_device_link`。
主机测试覆盖全部可打印字符输入、应用循环、网络工作任务故障、缓存故障、身份/HTTP/回执、
恶意报文、中文覆盖和真实 LVGL 尺寸；无线/NVS/RTOS 边界为模拟。浏览器测试操作真实本机
网站，其 HTTP 报文通过实际固件 C 解析器；浏览器测试的设备回执为模拟，不等于硬件验收。

实机需另行确认烧录：输入/显示/按键、真实扫描和正确/错误密码、配对上传回执、重启重连、
断网恢复、掉电持久性、TLS/校时和运行堆/栈余量。域名未定，未部署公网、未宣称公网联调完成。
精确镜像标识与测试结果见交付报告。

# 网站界面优化

访客阵容页与管理员工作台沿用现有 Python 和原生 HTML/CSS/JavaScript，不增加框架或外部字体依赖。固件与设备协议保持不变。

## 视觉方向

保留深色基调，使用炭灰背景、克制的蓝色操作按钮、暖色标题与简洁舞台字标。CSS 变量统一文字、背景、分隔线、焦点和操作颜色；中文字体使用本机回退，不依赖在线字体请求。

桌面左侧放日期与管理工具，右侧放演员阵容。手机保留单栏阵容，日期控件对齐，管理入口并排。演员表单、搜索结果、发布预览、城市设置和设备卡片统一文字层次、间距与控件状态。打开已有设备的列表时，配对区默认折叠；用户展开后，自动刷新不会打断填写。

## 访客与管理员

访客从现有公开接口读取已发布名单；无名单的日期或场次明确留空，网络和服务错误不冒充未发布。演出时间来自对应的冻结发布版本。管理员草稿仍需登录；保存、发布、上传依然分开，原有确认步骤保留。

弹窗具有可访问名称，控件区分焦点、按下和禁用状态。支持键盘跳到内容、异步操作后恢复适当焦点及减少动态效果偏好。选择演员仍不自动聚焦搜索；存储信息可以展开或收起。

## 验证

网站后端 56 项测试通过。Edge Chromium 触摸模拟覆盖 320、390、768 和 1280 像素，检查日期对齐、姓名艺名搜索、来源资料、城市时间设置、设备选择/备注/上传/删除、退出确认和存储操作。新增浏览器检查覆盖发布与草稿隔离、空名单、请求失败和配对填写期间的列表刷新。已查看访客、管理、演员资料和设备界面截图；真实 iPhone Safari 尚未测试。

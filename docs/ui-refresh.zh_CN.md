# 网站界面优化

访客阵容页与管理员工作台沿用现有 Python 和原生 HTML/CSS/JavaScript，不增加框架；字体随网站托管，不依赖第三方字体服务。固件与设备协议保持不变。

## 视觉方向

保留炭灰背景与蓝色操作按钮，采用紧凑的排班工具布局。去掉衬线标题、装饰字标、口号和步骤编号；标题、正文、数字与按钮统一使用用户上传的乔木字库思源黑体，以字号、字重和间距区分层次。首次加载字体约 2.44 MiB，之后浏览器缓存 7 天；字体未加载时文字仍可阅读。

本次筛选了 308 个已安装技能的说明，并参考 Salin UI 的布局/组件规范与 Impeccable Design Polish 的现有界面修整流程。桌面采用左侧筛选、右侧名单的两栏工作台，768px 以下改为单栏；组内间距 8–12px、区块间距 16–24px。手机控件至少 44px 高，输入文字 16px，主要发布按钮与次要保存、设备入口分层。

普通与粗体文件来自 `qiaomu-cover-fonts`，原文件未修改，随附 OFL 授权。演员历史资料中的“岺、張、槑”使用上传的 `koharu` 包内同系列 Noto Sans CJK SC 补字，只保留这三个字并重命名为 Liulaogen Sans Extras。字体由明确白名单路径提供，缓存只用于字体，账号及内容接口仍为 `no-store`。

桌面左侧放日期与管理工具，右侧放演员阵容。手机保留单栏阵容，日期控件对齐，管理入口并排。演员表单、搜索结果、发布预览、城市设置和设备卡片统一文字层次、间距与控件状态。打开已有设备的列表时，配对区默认折叠；用户展开后，自动刷新不会打断填写。

## 访客与管理员

访客从现有公开接口读取已发布名单；无名单的日期或场次明确留空，网络和服务错误不冒充未发布。演出时间来自对应的冻结发布版本。管理员草稿仍需登录；保存、发布、上传依然分开，原有确认步骤保留。

弹窗具有可访问名称，控件区分焦点、按下和禁用状态。支持键盘跳到内容、异步操作后恢复适当焦点及减少动态效果偏好。选择演员仍不自动聚焦搜索；存储信息可以展开或收起。

## 验证

网站后端 58 项测试通过，包含字体文件响应、缓存范围及路径限制。界面与随附资料共 1594 个不同汉字在普通、粗体加补字组合中均有覆盖；浏览器检查实际使用的字体，确认标题、正文、按钮和补字已加载自带字体。Edge Chromium 触摸模拟覆盖 320、390、768 和 1280 像素，检查日期对齐、姓名艺名搜索、来源资料、城市时间设置、设备选择/备注/上传/删除、退出确认和存储操作。新增浏览器检查覆盖发布与草稿隔离、空名单、请求失败和配对填写期间的列表刷新。已查看访客、管理、演员资料和设备界面截图；真实 iPhone Safari 尚未测试。
